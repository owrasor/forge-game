# Sair do mapa causa uma queda

Type: grilling
Label: wayfinder:grilling
Status: open

## Question

Se o combatente deixa o espaço da luta, isso é uma queda?

A queda já está fechada em [O que acontece quando um combatente morre](./06-o-que-acontece-quando-um-combatente-morre.md). Não reabrir o que ela faz: 3 segundos fora, volta num ponto de volta, só com a pistola. O desenho do espaço está em [Como é o mapa](./11-como-e-o-mapa.md).

Fechar se sair do espaço, cair para fora ou atravessar o limite conta como queda, com as mesmas consequências. A mesma regra vale para o jogador e para o bot.
